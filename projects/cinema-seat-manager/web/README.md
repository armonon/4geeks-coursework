# Cinema Seat Manager Website

The visual version of the Cinema Seat Manager TypeScript project.

## Features

- Clickable 8 × 10 cinema seat map
- Available, selected, and reserved seat states
- Live availability counts and ticket total
- First-available adjacent-seat suggestion
- Reservation confirmation and room reset
- Responsive keyboard-, touch-, and screen-reader-friendly controls

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verify

```bash
npm test
```
