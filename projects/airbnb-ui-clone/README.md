# Staybnb UI Clone

A mobile-first vacation-rental browsing experience built with Next.js 16, React, TypeScript, the App Router, and Tailwind CSS. It includes a searchable home page, sortable catalog, and interactive room detail route.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` — live search, category filters, simulated loading, and listing grid
- `/catalog` — price sorting, reusable listings, and responsive map area
- `/rooms/[id]` — simulated room loading, photo carousel, amenities, host, and guest counter

The screenshot-derived component specification and product brief are documented in [`context.md`](./context.md).
