# Lista de tareas por terminal con Python

Este proyecto implementa el ejercicio de 4Geeks usando solamente la biblioteca
estándar de Python. La aplicación permite agregar, eliminar, mostrar, guardar y
cargar tareas desde `todos.csv`.

```bash
python3 app.py
python3 test.py
```

Las funciones requeridas viven en `app.py`, como espera la plantilla oficial.
